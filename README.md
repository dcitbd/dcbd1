# Dream Cart BD - E-Commerce Platform

A feature-complete, modern e-commerce web application powered by Google Sheets backend, Google Apps Script, and responsive modern frontend.

## Key Features
- **Multi-Role User Portals**:
  - Customer Portal (Orders, Wishlist, Profile, Invoice Download)
  - Reseller Portal (Wholesale-to-Retail Margin tracking, Payment Requests with -3% deduction, Sales Reports)
  - Wholesaler Portal (Enforced Minimum Order Quantity, Bulk pricing)
  - Admin/Worker Portal (Protected with Captcha, Role-based permissions, Live Analytics, Products/Categories/Brands/Orders CRUD, PDF/CSV/Print exports)
- **Live Google Sheet & Apps Script Integration**:
  - Synchronized with Google Sheet: `1BGi8IXV6S7uXDi4IaR_sCJYhtpfzyLGuldo4NnGVmR8`
  - Automated HTML email alerts sent to `jainal.dcitbd@gmail.com`
- **Dynamic Pricing Engine**:
  - Customer price (Selling Price with crossed Original Price)
  - Reseller price & commission
  - Wholesaler price with minimum order quantity validation
  - Auto out-of-stock detection with "Pre Order" button switch
- **Fast Search & Interactive Floating Actions**:
  - Instant live search modal with product thumbnail preview
  - Dual-number WhatsApp quick chat & direct phone calling
  - Live chat support page
  - Dark mode and light mode theme switcher
  - Order success voucher with barcode and printable invoice
